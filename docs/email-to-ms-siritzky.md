**Subject:** Using the Wesley logo in a browser extension I've been building

Dear Ms Siritzky,

Over the last few months I've been building a browser extension for WiSE and it's pretty much finished. I've been running it on my own account every day, so it has had a fair amount of real use.

The point of it is to save time. It pulls announcements and homework from all my classes into one panel on the home page, so I don't have to open six class pages just to work out what's due. Timetable cards open up in place to show the latest post for that class. There's also a search that goes through announcements and the files teachers upload, which I built after losing a revision booklet somewhere inside Resources and never finding it again.

Two things I need to ask you about before I take it any further.

The first is the logo and the WiSE name. Right now it only borrows the school colours. I'd like to use the lion crest properly in the icon but I don't know who to ask about that. Is there a form for it, or is it someone in Marketing?

The second is publishing it. I want to put it on the Chrome Web Store and Edge Add-ons as my own project rather than a school product, but with the school's support and proper permission for the branding. Do you know which people would need to sign that off? My guess is IT and Marketing, but I'd rather ask than assume.

Nothing leaves the browser. It doesn't collect any data, and the optional AI part uses the user's own API key rather than anything of mine. I'm also happy to label it as unofficial, or to drop the crest entirely if that's simpler.

Happy to show you it running if that would help.

Thanks,
Chris Guo
Year 10
