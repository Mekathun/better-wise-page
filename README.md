# Better WiSE Page

A browser extension for the Wesley College WiSE platform. Test builds are published here.

**Latest: [v0.1.1-beta1](https://github.com/Mekathun/better-wise-page/releases/latest)** ·
**Download page: https://mekathun.github.io/better-wise-page/** ·
**Privacy: https://mekathun.github.io/better-wise-page/privacy.html**

## English

The extension rebuilds the WiSE home page: your next class, a to-do list made from course
announcements, a timetable that opens in place, and faster site search. It has no account and
no server. What it reads stays in your browser profile.

### Install

1. Download `Better_WiSE_v0.1.1-beta1.zip` from the latest release and unzip it. The folder must
   contain `manifest.json` at the top.
2. Open `edge://extensions` and switch on Developer mode.
3. Click Load unpacked and pick that folder.
4. Open `wise.wesleycollege.net` and refresh.

The release also has a `.crx`. Browsers block installing one from a download link, so use the
zip. If yours allows it, drag the file onto `edge://extensions`.

### Updating

The extension does not update itself. Remove the old copy on `edge://extensions`, then load
the new folder the same way.

### Privacy

Course pages are read on your machine and stored in your browser profile. Nothing leaves the
device unless you turn on the AI features and add your own API key. Full text:
https://mekathun.github.io/better-wise-page/privacy.html

Questions: chris.guo@wesleycollege.edu.au

## 中文

给 Wesley College 的 WiSE 平台做的浏览器扩展，这里只放测试版。主页会换成另一个样子：下一节课、
用课程公告生成的待办、可以直接展开的课表，还有更快的站内搜索。没有账号，没有服务器，读到的东西
都存在你自己的浏览器里。

### 安装

1. 从最新 release 下载 `Better_WiSE_v0.1.1-beta1.zip` 并解压。解压出来的文件夹第一层要能直接看到
   `manifest.json`。
2. 地址栏打开 `edge://extensions`，打开左侧的「开发者模式」。
3. 点「加载解压缩的扩展」，选中刚才那个文件夹。
4. 打开 `wise.wesleycollege.net` 刷新页面。

release 里还有一个 `.crx`。浏览器一般不允许从下载链接直接装 crx，所以用 zip 更稳。

### 更新

扩展不会自动更新。要换新版本，先在 `edge://extensions` 里移除旧的，再按上面同样的步骤加载
新文件夹。

### 隐私

课程内容是读在本机、存在你浏览器里的。只有你主动打开 AI 功能并填了自己的 API key，内容才会
离开本机。完整说明：https://mekathun.github.io/better-wise-page/privacy.html

有问题写信给 chris.guo@wesleycollege.edu.au
