# Better WiSE Page

A browser extension for the Wesley College WiSE platform. It rebuilds the home page with your
next class, a to-do list made from course announcements, a timetable that opens in place, and
faster search.

**Test build: [v0.1.0](https://github.com/Mekathun/better-wise-page/releases/latest)** ·
**Download page: https://mekathun.github.io/better-wise-page/**

This working copy is for people testing the extension before it goes to a store.

## Install (Edge, or another Chromium browser)

1. Download `Better_WiSE_v0.1.0.zip` from the latest release, then unzip it. The folder you get
   must have `manifest.json` inside it, at the top.
2. Open `edge://extensions` and switch on Developer mode.
3. Click Load unpacked and choose that folder.
4. Open `wise.wesleycollege.net` and refresh.

The release also has a `.crx` file. Browsers block those when they come from a download link,
so the zip is the one that works. If your browser does allow it, drag the file onto
`edge://extensions`.

## Updating

The extension does not update itself. To move to a newer build, remove the old copy on
`edge://extensions` and load the new folder the same way.

## Privacy

Everything the extension reads stays in your browser profile. There is no server and no
account. Course text only leaves your machine if you turn on the AI features and add your own
API key. The full policy is at https://mekathun.github.io/better-wise-page/privacy.html

# Better WiSE Page（中文）

给 Wesley College 的 WiSE 平台做的浏览器扩展。主页会换成另一个样子：下一节课、用课程公告
生成的待办、可以直接展开的课表，还有更快的站内搜索。

**测试版：[v0.1.0](https://github.com/Mekathun/better-wise-page/releases/latest)** ·
**下载页：https://mekathun.github.io/better-wise-page/**

这个仓库放的是上架前的测试版，给帮忙试的人用。

## 安装（Edge 或其它 Chromium 浏览器）

1. 从最新 release 下载 `Better_WiSE_v0.1.0.zip` 并解压。解压出来的文件夹里，第一层要能
   直接看到 `manifest.json`。
2. 地址栏打开 `edge://extensions`，打开左侧的「开发者模式」。
3. 点「加载解压缩的扩展」，选中刚才那个文件夹。
4. 打开 `wise.wesleycollege.net` 刷新页面。

release 里还有一个 `.crx`。浏览器一般不允许从下载链接直接装 crx，所以用 zip 更稳。
如果你的浏览器肯放行，也可以把它拖到 `edge://extensions` 里。

## 更新

扩展不会自动更新。要换新版本，先在 `edge://extensions` 里移除旧的，再按上面同样的步骤加载
新文件夹。

## 隐私

扩展读到的东西都存在你自己的浏览器里，没有服务器，也不用登录账号。只有你主动打开 AI 功能
并且填了自己的 API key，课程内容才会离开本机。完整说明：
https://mekathun.github.io/better-wise-page/privacy.html
