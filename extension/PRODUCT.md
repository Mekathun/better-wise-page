# Better WiSE — 产品介绍

> 把 Wesley College 的 WiSE 从「信息仓库」变成「今天该做什么」。
> 一个装在浏览器里的增强层，不动学校系统一行代码，把散落在公告、附件、课程大纲里的东西收拢成一屏可用的东西。

![version](https://img.shields.io/badge/version-0.1.3.6-6b3a79) ![platform](https://img.shields.io/badge/Edge%20%2F%20Chrome-Manifest%20V3-4a2057)

---

## 一、这是什么

**Better WiSE** 是一个 Edge / Chrome 扩展（Manifest V3）。安装后它会在 `wise.wesleycollege.net` 的首页、课程页和所有子页面注入一层增强 UI：

- 首页顶部多一块 **Today's plan** 面板：今天要做的事、快到期的作业、按行排列的任务卡
- 课表卡片可以点开，直接看这门课最新的公告内容
- 右上角多一个 **BW Search** 气泡，`Ctrl/⌘ + K` 或拖进导航栏，搜遍你的公告、文件、课程页
- 头像旁多一个 **BW Settings** 齿轮，弹出的就是完整设置面板，和浏览器工具栏里的插件弹窗是同一套、实时同步

它不代理登录、不改学校数据、不往任何第三方服务器发东西 —— 页面里渲染的一切，浏览器里存的一切，都还在你自己的机器上。

## 二、对口用户

| 人群 | 为什么需要它 |
|---|---|
| **Wesley College 在读学生（主力）** | 每天要看 WiSE，但 WiSE 是「信息仓库」不是「任务清单」：公告埋在每门课的 homepage 里，老师发的文件藏在 resources 目录六层深处，Due Work 页面只告诉你有什么作业、不告诉你今天要先做哪个 |
| **Year 10–12 / VCE 学生** | 课多、assessment 多、附件多。一个 term 里几十个文件，靠翻目录找「上次那个 revision booklet」几乎不可能 |
| **用学校小尺寸笔记本的学生** | 卡片按行排布、Cards per row 可调默认 6 列，小屏自动降列，不用横向滚动 |
| **中文背景 / 双语学生** | 支持**拼音搜索**（含 1 处打错容错）和繁简混排，中文课的文件用拼音也能搜到 |
| **性能敏感的用户** | 内置 Performance mode，一键关掉毛玻璃和阴影，老旧机器也能流畅滚动 |

不适合：老师端、家长端、其他学校（虽然底层是 Schoolbox，但课程接口、资源树都是 Wesley 专属）。想把逻辑搬到别的 Schoolbox 学校，需要替换 `search.js` 里的接口适配层。

## 三、解决了什么痛点

### 原生的 WiSE

```
想看今天的任务 → 打开每门课的 homepage → 找 Class Announcements → 一条条读
找老师发的文件 → Resources → 一级一级点目录 → 还未必记得是哪个单元的
找一条旧公告     → 只能靠翻，或去 /search 里手动点开高级搜索
想知道快到期的事  → Due Work 页面给你一长串，没有优先级
```

### 装上之后

```
首页一屏：今天要做什么 + 什么快到期 + 点开课表卡片直接看公告内容
一个气泡：Ctrl/⌘+K → 输入关键词 → 公告、附件、课程页、近一年 News 全在里面
一个齿轮：所有外观 / 性能设置即时生效，不用刷新
```

## 四、核心功能

### 1. 首页面板 · Today's plan

插在首页课表下方，和学校原有版式同宽、不遮挡 Calendar 与教师栏。

- **To do today**：按课程分组的任务卡，可 Tab 切换单门课，可自定义添加卡片
- **Due**：把 Upcoming Learning Activities 和课程公告里的作业合并，按剩余天数排序，勾选即完成
- **Upcoming assessment / test / exam**：单独一块，显示剩余天数
- **任务卡**：点开就是这条公告的全文详情 + 附件链接；右上角可隐藏/删除，有独立的编辑模式
- **折叠动画**：高度过渡用接缝化的 cubic-bezier，配合 Performance mode 可降级为纯透明度过渡

### 2. 课表增强

- 卡片**点开就地展开**，显示这门课最新公告的要点（不是跳走）
- 展开宽度按条目数自适应（26% 起步，最多 46%），其他列自动压缩
- 展开后的卡片会**溢出滚动条**呈现完整内容，而不会把整个页面顶下去
- **周末模式**：周六日自动显示「上一个上学日」的课表和任务，走 Calendar 接口取最近的有课日期
- 总开关是一个拟态「碗」：狮子液面灌金、悬浮抬升、点击下沉，紫金双色取自校徽

### 3. 本地任务解析

- 公告正文由本地解析器拆成「今天要做什么」的条目，不调用任何模型，不联网到 WiSE 以外
- **按帖子缓存**：同一篇公告只解析一次；只有跨天或有新公告才重新读
- **Re-read 安全提交**：新结果先写暂存区，全部跑通才覆盖旧缓存；失败则保留旧数据
- 0.1.2.4 起删除了全部 AI 相关代码与设置，旧版的模型、key、AI 缓存会在首次启动时清掉

### 4. BW Search · 全局搜索

**两个入口**：`Ctrl/⌘ + K`，或右上角悬浮气泡（默认在头像下方，可拖进导航栏停靠成 "BW Search" 导航项，也能反复拖出来）。

**双引擎**：

| 引擎 | 覆盖 | 特性 |
|---|---|---|
| 站点原生 `/api/search` | 近一年的 News、文件、页面、活动、课程单元 | 服务端检索，结果带 Curriculum 路径、发布时间、发布人 |
| 本地索引 | 877 条：752 个 resources 文件 + 38 条公告 + 26 个公告附件 + 23 个链接 + 3 个文件目录 | 秒出、离线可用、覆盖接口搜不到的老文件 |

**匹配能力**：

- **字面**：英文按词边界（2 字母整词、3–4 字母词首、5+ 子串），避免「pe」命中「open」
- **同义词 / 缩写**：`PE` `PHE` `phys ed` → Phys & Health；`LAE` `EAL`；`IAS` `HASS`；`MME` `methods`；`LLC`；`SCI`；`TUT`
- **拼音**：内置 20,924 字 / 410 音节表，支持连写（`xiaocaifeng`）、音节边界短词（`zha`）、**1 处编辑距离容错**（`caifang` → caifeng），繁简混排都能命中
- **课程名筛选**：输入科目名/缩写直接筛到该科目，alias 已写进每条记录

**筛选**：All · Posts · Files · Links · Pages（分段控件，白色高亮块带位移+缩放动画）。

**交互**：`↑↓` 选择、`↵` 在新标签页打开（**面板不关闭**）、`esc` / Close 关闭、`×` 清空输入、内容变少时面板高度平滑收缩。

### 5. BW Settings

导航栏头像右边、通知铃左边加了一个齿轮（用原生导航的结构和尺寸，和铃铛同一垂直中心线）。点开是 **300×640 的圆角非模态面板**：

- 内容直接加载插件自己的 `options.html`，所以和工具栏弹窗**完全同一套设置**
- 通过 `chrome.storage` 双向实时同步，改完即生效（多数选项不需要刷新页面）
- 点面板外部或 `esc` 关闭；外带轻微外阴影和 16px 圆角

### 6. 外观与性能

- **主题**：紫 `#64346f` / 金 `#b39037` 双色体系，背景柔光点、毛玻璃、卡片效果可分别调
- **Surfaces**：Tab 栏 / Section 头部的毛玻璃开关与不透明度
- **Cards**：每行卡片数（3–10，默认 6）、卡片尺寸、文字大小、链接/标题/详情独立字号、卡片不透明度、卡片特效
- **Layout**：卡片高度、Modal 宽度与内部字号
- **性能**：More animations / Smoother animations / Performance mode（关毛玻璃与阴影）/ Animation speed（0.25×–5×）

### 7. 日历增强 · Calendar Enhance

首页 Calendar 那格的标题右边常驻三个小控件：`‹` `›` `Today`，最右端再跟一颗方形的日历按钮。默认什么都不做，那格还是站点原生的日历。

- `‹` `›`：直接翻到前一天/后一天，不用先打开任何东西
- `Today`：跳回今天
- 日历按钮：在列表上方落下一张月历浮层（不挤动下面的内容），按钮同时点亮；`‹ ›` 翻月，今天和已有活动的日子带小圆点

选中某天，浮层收起，那格换成那天的列表 —— 直接用站点 FullCalendar list 视图那套 class，没有 `Time / Event` 表头行，all-day 和具体时间混排，事件前带来源颜色的小圆点，日头写作 "Thursday November 12th 2026"。点浮层外面也会收起。按钮的高亮只表示"这张浮层还开着"。

刷新页面回到原生日历。

内容来自站点自己的日历接口（`/calendar/ajax/full`，和原生那格同一份数据），但**减掉了固定课表里的每一节课**，以及 `Day 9` 这类只有轮次编号的条目 —— 那些在课表格子里已经有了，列在这儿只是噪音。留下的是一次性的事件：考试、集会、体育、音乐、due work。

状态不落盘：每次打开页面都是原生日历，也不会记住上次翻到了哪天。

## 五、产品特色（和别人不一样的地方）

1. **零配置开箱可用** —— 不用登录任何账号、不用填任何 key，装上就能用
2. **不吃学校页面** —— 全部用独立命名空间（`wt-` / `wt-sr-`）注入，SPA 路由切换会自动清理，不留残影
3. **搜索是双引擎** —— 站点接口负责「全」，本地索引负责「快」和「老文件」，两边的结果合并去重
4. **中文友好** —— 拼音 + 繁简 + 同义词，是这类校园插件里少见的
5. **不依赖外部服务** —— 不发任何请求到 WiSE 以外的服务器，没有配额、没有限流、没有第三方可用性风险
6. **原生感** —— 停靠进导航栏的按钮复刻了原生 `<li><a><sbx-icon><span>` 结构和 15px/24px 的行内节奏，图标顶边、文字基线、li 高度逐像素对齐
7. **隐私边界清晰** —— 只有一个 host permission（`wise.wesleycollege.net`），没有 API key、没有模型设置、不上传任何第三方

## 七、快速上手

1. 装扩展：`wesley-cards-extension.crx` 双击安装，或解压 ZIP 后在 `edge://extensions` 开开发者模式 → 「加载解压缩的扩展」

## 八、技术实现

**结构**

```
manifest.json        MV3 清单（两个 content script 入口）
home.js              首页面板 / 课表增强 / 模态 / 设置浮层
search.js            全局搜索：索引、匹配、UI、悬浮气泡、设置面板
pinyin-data.js       20,924 字拼音表
options.html/js      BW Settings 的完整设置页
build-extension.mjs  打包脚本（zip + CRX3 签名）
```

**数据来源**

| 内容 | 接口 |
|---|---|
| 课程列表 | `/learning/classes`（解析 `.v-card`） |
| 公告 | `GET /news/lists/folder/<id>?l=50` |
| 公告附件 | `GET /news/<id>` 里的 `ul.article-files` |
| 课程文件 | `GET /resources/<homepageId>/nodes`（递归课程 → 单元 → 子页） |
| 站点搜索 | `GET /api/search?keyword=&filter={"date":{...},"types":[]}` |
| 课表 | 首页 DOM + `/calendar/ajax/full?start=&end=&userId=` |

**权限**：`storage` + 一个 host permission（`wise.wesleycollege.net`）。没有 `tabs`、没有 `<all_urls>`、没有 `webRequest`，也不连任何外部服务器。

## 九、已知限制

- **只适配 Wesley College 的 WiSE**：接口路径、资源树结构都是学校专属
- **本地索引有上限**：每门课 resources 递归深度 ≤ 4、请求数 ≤ 16，公告最深 30 条、附件深挖 6 条；超出的部分搜不到
- **解析靠文本规则**：公告写得太含糊时，本地解析器抓不到条目（卡片会变薄，但不会空）
- **拼音容错只有 1 个编辑距离**：`balizhake`（比 `baerzhake` 差 2 个字符）这类按方言习惯打的搜不到
- **搜索时间窗**：站点接口默认近一年（-1y/+1y），更早的内容要靠本地索引
- **设置面板宽度固定 300px**：因为 `options.html` 本身是按浏览器弹窗的 300px 设计的
