# 给新会话的开场白

新开一个会话（或换了模型），把下面对应的一段原样丢过去，它就知道该读哪儿、别读哪儿。

---

## 最短的一句

```
先读 D:\DSH\Better_WiSE\vault\000-入口\00-首页.md，按里面的触发词表取文件，别通读整个库。
```

这一句够用。首页会把它引到 L0 或某一篇专题卡。

---

## 标准版（要它接着干活）

```
工作目录 D:\DSH\Better_WiSE。这里有一套 Obsidian 记忆库：

1. 先读 vault\000-入口\00-首页.md（约 1.1k token），再从 vault\000-入口\L0-钉住上下文.md 取 goal / 硬约束 / 已做完。
2. 只读触发词表里点到的那一两篇，不要遍历目录、不要通读 300-轮次记录。
3. 需要某轮细节，先看 vault\300-轮次记录\00-轮次索引.md 的表，再点开那一篇；每篇都带原文行号，可以回 PROGRESS.md 对。
4. 断言必须带 文件:行号。不确定就说不确定，别补。
5. 做完一轮：把这一轮追加到 PROGRESS.md 末尾（格式照上一节），然后跑
   python vault\scripts\sync.py && python vault\scripts\check.py --quiet
6. 改完手写层要顺手更新链接它的那一篇，别留下孤儿。
```

## 只问不做的版本

```
读 D:\DSH\Better_WiSE\vault\000-入口\00-首页.md，回答我：<问题>。
只读能回答这个问题的那一篇，读完把出处（文件:行号）给我。
```

---

## 给别的 AI（不给文件系统权限时）

把 `vault\000-入口\L0-钉住上下文.md` 和对应那一篇专题卡的内容直接贴给它。这两个加起来约 3.5k token，够回答大部分「这项目是什么、做到哪了」的问题。
