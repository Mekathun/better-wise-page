# L1 总览地图

首页告诉你「去哪」，这一页告诉你「那里面具体有什么」。只在首页不够时读。

---

## 一、项目一句话

学校门户 WiSE 是个信息仓库：公告埋在每门课里，文件藏在六层目录下，Due Work 只给一长串不给优先级。Better WiSE 是一个 MV3 扩展，在页面上注入一层 UI，把它变成「今天该做什么」。不改学校一行代码，不发任何数据出去。

完整能力清单在 [[100-项目/00-扩展总览]]。

---

## 二、代码长什么样

| 文件 | 行数 | 干什么 | 什么时候进去 |
|---|---|---|---|
| `extension/manifest.json` | — | MV3 清单，三段 content_scripts，`key` 锁死扩展 ID | 改注入时机、加页面、加权限 |
| `extension/boot.js` | 59 | `document_start` 抢首帧：定主题、挂版式微调 | 首帧闪烁、版式错位 |
| `extension/color-fix.js` | 123 | 站点自带颜色的纠正 | 颜色语义被暗色压掉 |
| `extension/theme.css` | 889 | 全站暗色，889 行，`!important` 密集 | 任何「某处还是白的」 |
| `extension/home.js` | 6655 | 主力：面板、课表、日历、主题、设置弹层 | 大部分改动在这 |
| `extension/search.js` | 2360 | BW Search + 站点级主题 | 搜索、`Ctrl/⌘+K` |
| `extension/options.html` / `.js` | 519 / 859 | 设置面板（独立页 + 弹层共用） | 加开关 |
| `extension/pinyin-data.js` | 1（压缩表） | 拼音音节表，静态无逻辑 | 搜索命中率 |
| `extension/build-extension.mjs` | 82 | 打包：zip + CRX3 + 复制到根目录 | 出包 |

目录里还有什么，看 [[100-项目/01-文件地图]]。

## 三、三条常走的路

### 路 A：用户报「某处还是白的」
1. [[400-知识库/02-CSS注入与坑]] —— 先确认注入顺序和 `!important` 的规矩
2. `extension/theme.css` 里 grep 那个区块的类名
3. 起测试浏览器验证：`tools/probe/live-ext.mjs` 的启动命令在 L0 里
4. 验收脚本 `tools/probe/audit.mjs`（逐页白块审计）

### 路 B：要出包
```
node extension/build-extension.mjs
```
产物自动落到根目录 `Better_WiSE_v<version>.crx/.zip`。版本号规则、密钥、Edge pack 那条命令的坑，全在 [[100-项目/02-构建与发布]]。

### 路 C：校方问「你这东西会不会泄露数据」
1. [[100-项目/03-数据与隐私]] —— 权限清单、数据流向、能说和不能说
2. [[100-项目/04-与校方沟通线]] —— 已经谈过什么、对方什么态度、我方退到哪
3. 原文在 `600-素材与样本/原文/`：`SECURITY-REVIEW.md`（英文审查包）、`IT-MEETING.md`、`TEACHER-TALK.md`

## 四、目录之间的关系

```
000-入口   ← 所有东西的入口，改任何目录都要在这里留一行
 ├─ 100-项目      项目本体：是什么、怎么建、数据去哪、跟学校的线
 ├─ 200-界面      代码侧：八块 UI，每块一篇，函数级行号
 ├─ 300-轮次记录  时间侧：64 轮，按真实日期排
 ├─ 400-知识库    原理侧：站点怎么长的、CSS 怎么打架、MV3 怎么打
 ├─ 500-决策      结论侧：只记选了什么、为什么
 ├─ 600-素材与样本 原料侧：docs 14 份原文 + 素材在哪
 ├─ 700-归档      原文：PROGRESS.md 全本，行号对得上 300 的笔记
 └─ 900-模板      新建时照抄
```

四条线各自回答一个问题：**是什么**（100）、**怎么实现**（200）、**什么时候做的**（300）、**为什么这样做**（500）。查东西先想清楚你要的是哪一个，能省一半翻找。

## 五、生成层与手写层的边界

| 问题 | 归属 |
|---|---|
| 「0.1.2.9 那轮改了什么」 | 生成层。`300-轮次记录/2026-11/0NN-*.md` |
| 「课表 next day 的实现在哪」 | 手写层。[[200-界面/02-课表]] |
| 「为什么把 AI 功能删了」 | 手写层。[[500-决策/0001-删除AI功能]] |
| 「PROGRESS.md 第 1595 行写了啥」 | 生成层副本。`700-归档/PROGRESS.md` |
| 「docs 里那份安全审查包原文」 | 生成层副本。`600-素材与样本/原文/SECURITY-REVIEW.md` |

判断方法：**能不能从别的文件重新算出来**。能，就是生成层。
