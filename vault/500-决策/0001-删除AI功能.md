# 决策 0001 · 删除 AI 功能

**决定**：0.1.2.4 起，扩展里不再有任何 AI 调用。面板的 AI 摘要按钮、设置里的模型选择与 API key 输入、manifest 里的外部域 host 权限，全部删掉。

**日期**：2026-11-12，与校方 IT 谈话的当天。

---

## 为什么

谈话结论两条：AI 涉嫌把学生可见内容外发；公开分发不被允许。第一条是技术事实，没有辩解空间 —— 开着 AI，公告正文就会发给外部端点，那不是「只读」能兜住的。

## 当时考虑过的替代

| 方案 | 为什么不选 |
|---|---|
| 保留 AI 但默认关、要自己填 key | 仍然存在外发路径，评审时说不干净 |
| 换成校内端点 | 学校没有这个服务，也不给个人开 |
| 保留代码但不接线 | 评审看代码，删不干净等于没删 |

## 代价

删变量时漏了一处引用：`buildSummary()` 里还传着 `aiToggle`，`ReferenceError` 让整个面板卡在骨架屏。0.1.2.5 才修。

教训记在那一轮：删一个被引用的变量，`node --check` 抓不到，必须实机跑一遍。

## 现在的状态

`host_permissions` 只剩 `https://wise.wesleycollege.net/*`，`permissions` 只剩 `storage`。`fetch` 全部同源。这条线以后不要再往回加。
