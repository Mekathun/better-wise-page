# 数据与隐私

这一页是回答「你的插件会不会把学校数据传出去」时的底稿。校方问过，答案在 0.1.2.4 之后变得很干净。

---

## 权限：只有两项

| 项 | 值 |
|---|---|
| `host_permissions` | `https://wise.wesleycollege.net/*`（仅此一个域） |
| `permissions` | `storage` |

没有 `tabs`、没有 `webRequest`、没有 `cookies`、没有 `<all_urls>`。0.1.2.4 之前有一条外部 AI 端点的 host 权限，已经删掉。

---

## 数据存在哪：全在本机

两个 storage，都在浏览器本地，不经过任何服务器：

| 区 | 存什么 | 典型键 |
|---|---|---|
| `chrome.storage.local` | 面板状态、主题、日历开关、自定义背景图、日志 | `theme`、`calEnhance`、`lastNewsId`、`bgImage`、`wesleyLogs`（截尾 500 条）、`shortcuts`、`wesleySearchStats` |
| `chrome.storage.sync` | 用户设置（跨设备同步，走 Chrome 自己的账户） | `DEFAULT_SETTINGS` 那一组：`lang`、`themeFrom`/`themeTo`/`themePreset`/`themeOpacity`、`animations`、`smooth` 等 |

`chrome.storage.sync` 是浏览器的内建能力，不是我们的服务器。这一点要说清楚，否则容易被理解成「你们有云端」。

---

## 网络请求：只打学校自己的域

代码里 `fetch` / `XMLHttpRequest` 的出现次数：

| 文件 | 次数 |
|---|---|
| `extension/home.js` | 15 |
| `extension/search.js` | 7 |
| `extension/options.js` | 1 |
| `boot.js` / `color-fix.js` / `pinyin-data.js` | 0 |

全部同源，`credentials: 'same-origin'`。典型端点：

- `GET /calendar/ajax/full?start=<unix>&end=<unix>&userId=<id>` —— 日历全量（2026-11 实测 177 条）
- 课程页、资源树、`/search` —— 都是用户自己登录后本来就能打开的页面

没有服务器、没有账号体系、没有埋点、没有第三方 SDK。

---

## 一句能背下来的说法

> It reads the pages I can already open when I'm logged in as myself. It doesn't touch anyone else's account, and it can't see grades or profiles I don't already have access to. Everything it reads is stored in my own browser, on my laptop. There is no server, no account, and no analytics.

被追问「那不就是批量抓取」时，承认这一半，然后给数字：一天扫一次，最多四十门课，三个并发，只抓自己能看到的东西。原文在 `600-素材与样本/原文/IT-MEETING.md`。

---

## 0.1.2.4 删掉了什么

| 删掉 | 为什么 |
|---|---|
| 面板上的 AI 摘要按钮和整条调用链 | 会把学生可见内容发给外部模型端点 |
| 设置里的模型选择与 API key 输入 | 同上，且 key 存在本地也不该留 |
| manifest 里的外部域 host 权限 | 只留学校域 |

副作用：删变量时漏了一处引用，`buildSummary()` 抛 `ReferenceError`，整个面板卡在骨架屏。下一轮才修（[[300-轮次记录/00-轮次索引]] 0.1.2.5）。

---

## 不要写进任何文件的东西

账号、密码、cookie、BDUSS、API key。用户曾在会话里给过测试账号，L0 里明确记着「不写进任何文件」。`check.py` 有一组正则专门抓这类串，抓到会报「敏感串」。
