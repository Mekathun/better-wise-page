## 找东西的三条捷径

```bash
# 某个函数定义在哪
grep -n "function 函数名" extension/*.js

# 某个 CSS 类名被谁用
grep -n "wt-类名" extension/*.js extension/theme.css

# 某个结论是哪一轮得出的
python vault/scripts/check.py   # 先确认库是好的
grep -rn "关键词" vault/300-轮次记录/2026-11/
```
