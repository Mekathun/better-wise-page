# 深色主题 Dark Theme

一句话：只靠 `html[data-wt-theme="dark"]` 一个属性 + 两套 CSS token 换皮，切换过程不做过渡。

`注入点 extension/theme.css:L1 token · extension/boot.js:L7 首帧定色 · home.js:L5760 applyTheme`

## 它做什么

| 阶段 | 谁做 | 干什么 |
|---|---|---|
| 首帧 | `boot.js` `document_start` | 读 `localStorage.wesleyTheme` 先把 `data-wt-theme` 写对，避免白闪 |
| 校正 | `boot.js:L24-34` | `chrome.storage` 回来发现不一致就改回来，chrome.storage 才是真值 |
| 配色 | `theme.css:L1-55` | `--wt-t-*` 两套：亮色白底紫强调，暗色中性深灰 |
| 首页 | `home.js:L5760 applyTheme` | 只写属性 + `rememberTheme` + `paintPageBackground` |
| 其它页 | `search.js:L2328 applySiteTheme` | 同一个属性，另一条代码路径 |
| 补丁 | `theme.css` 各段 | 站点写死颜色的地方逐块压暗 |
| 文本 | `color-fix.js` | 正文里内联近黑 `color` 的提亮到可读 |

## 关键函数

| 函数 | 行 | 作用 |
|---|---|---|
| `themeIsDark()` | home.js:L5736 | dark / light / system 三态判定 |
| `paintPageBackground()` | home.js:L5742 | 深色下把 body 背景存进 `dataset.wtLightBg` 再置 `#121013` |
| `applyTheme(pref)` | home.js:L5760 | 写 `root.dataset.wtTheme`，别的什么都不做 |
| `resyncTheme()` | home.js:L5783 | focus / visibilitychange 时对一次 storage |
| `applySiteTheme(mode)` | search.js:L2328 | 非首页入口；切亮时移除 `#wt-boot-theme` |
| `fixOne(el)` | color-fix.js:L59 | 相对亮度 < 0.34 才提亮，目标 0.72 |
| `sweep(root)` | color-fix.js:L70 | 只在 dark 下跑，扫 `#content article [style*="color"]` |
| `LOGO_CSS` | color-fix.js:L86 | 只对 `skin_logo_large` 反白 |

## 约束与坑
- **不做亮暗过渡**，这是结论不是遗漏：整屏蒙版只淡背景、`transition` 常驻类被站点 62ms 重写 class 打乱、`adoptedStyleSheets` 方案成立但两千多条颜色同一下场仍是一跳，三种都试过（`applyTheme` 上方 L5750-5759 注释）。
- 深色 body 背景用纯色不用渐变：渐变不能插值，切换时背景会硬跳、和别的板块不同步（`paintPageBackground` L5742 注释）。
- 暗色 token 块在 `theme.css` 里写了两遍（L26 与 L56 附近），后一份生效；改配色要两份一起改，或者干脆合并。
- `theme.css` 里 `data-wt-theme` 出现 541 次：绝大部分是局部补丁，按段落注释找（L324 课表卡保留柔色底所以字仍用深色、L330 日历链接 `#64346f` 暗底隐形、L390 搜索层、L421 复选框、L470 模态逐层、L548 Due 卡纯红对比度 1.6、L571 Highcharts 画在 SVG rect 里改不到背景、L698 flatpickr、L753 `#profile-options`）。
- `boot.js` 只许改位置不许锁宽度：`.sbx-header-search` 被写死 `right:170px`，一旦给 width，站点 `:hover{width:100%}` 就会跳位（boot.js:L42-49 注释）。
- 造 DOM 的 `el()` 都打 `data-wt-ui`，`theme.css:L857` 在这颗元素上把站点 button 变量归零，否则 hover 会把按钮刷白。
- 性能模式是 `html.wt-perf`（theme.css:L682、L805），只砍重绘范围与投影，不砍动画；动画速度统一走 `--wt-spd`（theme.css:L620）。
- `color-fix.js` 只动近白/近黑，纯色块不动；logo 只处理带透明的 `skin_logo_large`，`skin_logo_square` 是不透明紫块会变纯白（L86 注释）。
