# 设置面板 Options

一句话：扩展自己的设置页（新标签页打开），一个主面板 + 两个抽屉；所有改动同时写 `storage.local` 与 `storage.sync`。

`注入点 manifest.json options_ui → options.html · 页面内还有两处快捷弹层（见下）`

## 它做什么

| 区块 | 内容 | 位置 |
|---|---|---|
| 主面板 | 总开关 `#inject`、主题三选 `#themeSeg`、动画/性能开关、速度滑杆、`#applyNow` | options.html:L383-424 |
| `#sheet` 详细设置 | tab 栏与分节的不透明度、每行卡数、卡片尺寸、字号、背景、模态尺寸 | options.html:L448-482 |
| `#feedback` 反馈抽屉 | 只读，`#feedbackClose` 关闭 | options.html:L436-446 |
| 页脚 | `#gear`、版本 `#footVer`（0.1.2.17）、`#feedbackBtn` | options.html:L431-433 |
| 首页快捷弹层 | tab 条右边齿轮 | home.js:L3588 `settingsPopover` |
| 搜索快捷弹层 | 铃铛左边的齿轮 | search.js:L2050 / L2090 / L2109 |

## 关键函数

| 函数 | 行 | 作用 |
|---|---|---|
| `DEFAULTS` | options.js:L1-39 | 全部默认值，`theme:'system'`、`rowMax:6`、`bodyOpacity:55`、`modalWidth:520` |
| `render()` | options.js:L173 | 按 `state` 回填所有控件 |
| `save(patch,label)` | options.js:L249 | `storage.local.set` + `storage.sync.set`，回调里 `flashVersion` |
| 初始化 | options.js:L257-260 | `local.get(null)` + `sync.get(DEFAULTS)`，合并顺序 `DEFAULTS → sync → local` |
| 一次性迁移 | options.js:L261-286 | `migrFont100` / `migrRow6` / `migrTs180` 三个标记位 |
| `chrome.storage.sync.remove` | options.js:L288 | 把 `bgImage`、`themeFrom` 等从 sync 里清掉 |
| `applyPopupTheme` | options.js:L114 | 设置页自己也跟随 `theme` 与系统 `matchMedia` |
| `settingsPopover` | home.js:L3588 | 首页 tab 条的齿轮弹层，改的是同一批 storage key |
| `placeSetPanel` | search.js:L2090 | 面板定位，宽度按 CSS 的 300px 算 |

## 约束与坑
- `bgImage` 只进 `local`：base64 图片太大，`sync` 会超配额，所以 `options.js:L288` 专门把它从 sync 移除。
- 迁移只能跑一次，全靠 `migr*` 标记；重复跑会把用户调好的字号再放大 1.25 倍（`options.js:L261-286`）。
- `save` 里两个 storage 都写（`options.js:L249`），只写一个会出现「换台电脑设置丢了」或「本机改了没生效」。
- 滑杆的显示值不是原值：`speedToPos` / `posToSpeed`（`options.js:L136-140`）负责 0-100 与 0.25-5 的映射，直接改 `value` 会错位。
- 三个字号滑杆带 `data-min="50" data-max="200"`（options.html:L460-465），`render()` 对这批 id 单独跳过，别照别的滑杆改。
- 页面内的齿轮弹层有同一类坑：开合不能读 `.show` 类，后台标签 rAF 冻结会留下透明层吃掉点击（search.js:L2040 注释，显式布尔 `setOpen`）。
- `#applyNow`（options.html:L383）是唯一让已开着的页面立刻重读设置的按钮，改完设置刷新没变先看它。
