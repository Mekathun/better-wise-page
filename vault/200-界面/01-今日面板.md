# 今日面板 Today Panel

一句话：首页课表旁边那块自己画的卡片墙，To Do 与 Due 两段，数据来自站点帖子与作业页。

`注入点 extension/home.js:L4134 buildSummary(state) · 容器 L1124 placePanel`

## 它做什么

| 段 | 内容 | 数据来源 |
|---|---|---|
| To Do | 每门课最新帖子里的任务卡，按科目分 tab | `taskCardsFor` L1408 读 `latestPost`，`normItems` 解析 |
| Due | 作业页抓来的到期项 + 老师帖里写的 Due | `fetchDueWork` L2743 → `dueFor` L2786 |
| Upcoming | 未来评估列表，可 `−` 删除 / `+` 恢复 | `upcomingBlock` L3841，`examSeedList` L3828 只为特定账号塞占位考试 |
| 自建卡 | 用户手加的卡 | `customCards` L1553，存 localStorage |

两块各有一套 tab 条（All + 每门课）和一个齿轮弹层，互相独立。

## 约束与坑
- 周末 `state.header` 是 null，`buildSummary` L4134 起首几行专门写了「不能直接 return」，否则面板永远停在骨架。
- 同一天课表里没有的课也要能在 tab 里出现，靠 `refreshExtraClasses`（buildSummary 内，L4134 起）从 `ALL_SUBJECTS` 合并，最多 8 门，`tutor group` 被排掉。
- 同一门课站点会写成 `G/M10LAEO-` 与 `G/M10LAE0-`（字母 O 与数字 0），只比 code 会多出一门假课，所以还有 `haveNorm` 归一化比对（buildSummary 内）。
- 空列表文案分两种：有隐藏卡时提示去 Settings → Edit（`renderTaskTab` L3967 尾部）。
- 卡片正文先出、正文后台补：`enrichDueList` L3229 只改卡片文字，不整块重排。
- 自建卡必须带 `custom` 标记，否则删除走站点卡那条路，`wesleyCustom` 里会留垃圾（`renderDueTab` L3997 内注释）。

## 同名两份，别改错

`taskCard` 这个名字在 `home.js` 里出现两次：L1418 一份（在 `taskCardsFor` L1408 旁边），L2830 一份。真正跑的是 L2830 那个，L1418 那份在别的作用域里，改了看不到效果。动手前 `grep -n "function taskCard"` 确认一遍。
