# 日历 Calendar

一句话：在首页右侧 Calendar 岛里塞一个自己的日期选择器和当天列表，走站点自己的日历接口。

`注入点 extension/home.js:L6636 initCalendarEnhance() · 岛探测 L6571 calIsland`

## 它做什么

| 部分 | 说明 |
|---|---|
| 标题栏 | `‹ › Today` 常驻（`calNavNode` L6560）+ 一颗日历图标（`calIconNode` L6536） |
| 图标按钮 | 只开合月份选择器，不改下面显示什么（`calIconNode` L6536） |
| 日期列表 | 自己画一张 FullCalendar list 结构的表（`calListTable` L6351） |
| 月份选择器 | `calRenderPick` L6379，7 列、周日开头、有事的日子补小圆点 |
| 状态机 | `CAL.on`（看某天）/ `CAL.pick`（选日子）两个布尔，`calSync` L6514 只对状态不重建 DOM |

| 函数 | 行 | 作用 |
|---|---|---|
| `calUid()` | L6232 | userId 三级回退：`window.fullCalendarConfig` → 扫 `<script>` 正则 → localStorage `wesleyCalUid` |

| `calNorm(list)` | L6264 | 扔掉 `type24`（固定课表）与 `Day N` 标记 |

## 约束与坑
- `userId` 是接口必填，缺了站点回 400 错误页（`calUid` L6232 注释）。
- URL 不能带 `folderId=`（空值直接回空数组），也不能带 `componentInstanceId`（会漏掉别的来源），`calFetch` L6245 注释。
- 列表不要加 thead：FullCalendar 会把 thead 挪到 `left:-9090px` 并回写 `th` 宽度，手搓表格一碰就散（`calListTable` L6351 注释）。
- 实测原生尺寸：时间列 150px、圆点列 34px、行高 39px、分隔线 0.6px `rgba(255,255,255,.1)`（同函数注释），改样式别破这几个数。
- 默认就是原生日历：`CAL.on` 只由选日期/翻日翻成 true，不读任何持久化状态（`calEnsure` L6580 尾部）。
- `calSync` L6514 每 1600ms 跑一次，只能改 `aria-pressed` / `display`，重建 DOM 会打断用户操作。
- 曾在 `tick()` 里加 `document.hidden` 早退，结果后台窗口永远插不进按钮，看着像随机失灵（`initCalendarEnhance` L6636 注释），已被去掉。
- 离开首页要收干净：`cleanupIfLeaving` L6030 删 `[data-wt-cal]`、`[data-wt-cal-pop]`、`.wt-cal-island` 与标题栏里塞的按钮。
