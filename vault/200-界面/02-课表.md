# 课表 Timetable

一句话：把站点那张 `table.timetable` 换皮、补标题、算星期与 Day 号，并且能原地切到下一个上学日。

`注入点 extension/home.js:L5812 main() · 面板 L1124 placePanel`

## 它做什么

| 能力 | 做法 |
|---|---|
| 换皮 | `main()` L5812 给表加 `wt-table`，给每个 `td` 加 `wt-card` + `role=button`（L5930 附近） |
| 点开卡片 | `expand(i, state)` L1485 展开当天帖内容，`collapse` L1518 收回；监听 `resize` 自动收 |
| 补标题 | `ensureTtHead` L1982：站点没有 `[data-timetable-header]` 时自己插一个 `h2` |
| Day N | `loadTtGrid` L4382 抓 `/timetable` 建 Day 1..10 表，`dayNumForDate` L4428 按「代码命中最多个」反推 |
| 周次 | `renderWeekChip` L2027 调 `schoolWeek` L1691 写 `Week N` |
| 原地切日 | `swapNextDay` L4796 造替身表横向推入，再点回到今天 |
| 挑日子 | `openNextDay` L4508 全屏 modal，`Day ·` 按钮 + 日历按钮 |
| 周末 | `WEEKEND_MODE` L5282 / `buildSyntheticTimetable` L5285 兜底画上一/下一个上学日 |

## 约束与坑
- 站点只在有课日渲染 `[data-timetable-header]`，周末压根没有，所以 Day 号只能自己算，不能读 DOM（`loadTtGrid` L4382 顶部注释）。
- 周末站点给的是「Last school day」残表，不是今天的课表，认标题能省掉 20 秒白等（`waitTable` L5872 分支）。
- 面板已经渲染过就别重做：`main()` L5898 附近查 `[data-wesley-home]:not(.wt-skel)`，但骨架不算，骨架就是要被替换的。
- 连点保护是 `window.__wtTtBusy`（`swapNextDay` L4796）；不清 `.wt-tt-alt` 就会叠出两层表，只能靠 `clearSwap` L4754。
- 原表在切走后 420ms 才 `visibility:hidden`，不然动画中途会在替身表底下露出半张（同函数内）。
- `main()` 里那份 `nextSchoolDay` 是闭包内的，模块级另有 `nextWeekday` L1964，别混用。
- 换页要收干净：`cleanupIfLeaving` L6030 会删 `wt-table` 类与 `.wt-tt-open` 的高度，`HOME_RE` L6029 定义哪些路径算首页。
