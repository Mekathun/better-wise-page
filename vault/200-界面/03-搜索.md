# 搜索 Search

一句话：全站一个搜索层，本地索引 + 站点 `/api/search` 两路结果，字面/同义词/拼音都能命中。

`注入点 extension/search.js:L2340 initTheme() · 入口气泡 L1880 placeFab · 开放 L1808 open`

## 它做什么

| 部分 | 说明 |
|---|---|
| 入口 | 可拖拽浮球（`placeFab` L1880）或停进导航栏（`fitDock` L2232），`Ctrl/⌘+K` 永远可用 |
| 本地索引 | `crawl` L647 抓课程帖子与附件，存 localStorage `wesleySearch:v6`（常量 L12-25） |
| 增量 | 只重爬过期课（`classStale` L635），三次并发 worker，按 `e.k` 合并 |
| 站点结果 | `serverSearch` L715，去抖 220ms（`SERVER_DEBOUNCE` L25），永远排在本地结果之后 |
| 语法 | `parseQuery` L1000：`@科目`、`"短语"`、`-排除`、`title:`、`kind:pdf` |
| 排序 | `scoreEntry` L1255，自己科目 +140 分压过标题命中 |

## 约束与坑
- 内容脚本可能被注入多次，靠 `html.dataset.wtSrLoaded` 与 `window.__wtSearchLoaded` 双重去重（L5 起）。
- 本地索引有数量上限 `MAX_ENTRIES=12000`，按时间裁最旧的（常量 L12-25）。
- 站点结果来自全校甚至别的校区，等 5 秒回来也不许插到本地结果前面，`mergeResults` L1328 注释写明，`paintRows` L1644 画一条「From WiSE search」分隔。
- 设置面板的开合状态用显式布尔 `setOpen`，不能读 `.show` 类：那类是在 `requestAnimationFrame` 里加的，后台标签 rAF 被冻结，会留下一个透明层吃掉点击（L2040 附近注释）。
- 面板宽度 CSS 写死 300px，`placeSetPanel` L2090 用 `offsetWidth || 300`，写 392 会横偏 92px。
- 快捷键：`DEFAULT_SHORTCUTS` L2268，`onGlobalKey` L2298 在 capture 阶段接，输入框里只放行 search。
- `el()` L174 会给每个节点打 `data-wt-ui`，否则站点 `button:hover` 的优先级会把背景刷白。
