# MV3 打包要点

一句话：三段 `content_scripts` 决定「什么在什么时候进哪个页面」，`manifest.key` 把扩展 ID 钉死，`build-extension.mjs` 一次出 zip + CRX 并复制到根目录。

## 三段注入各管什么

| # | matches | 文件 | 时机 | 管什么 |
|---|---|---|---|---|
| 1 | 全站 `https://wise.wesleycollege.net/*` | `boot.js`、`color-fix.js`、`theme.css` | `document_start` | 首帧主题、版式微调、站点彩字纠正、全站暗色（manifest.json:27-40） |
| 2 | 只有 `/`、`/home`、`/dashboard`、`/dashboard/*` | `home.js` | `document_idle` | 面板、课表、日历、设置弹层（manifest.json:41-52） |
| 3 | 全站 | `pinyin-data.js`、`search.js` | `document_idle` | BW Search、非首页的主题维持（manifest.json:53-62） |

权限只有 `storage` 一条，host 只开学校域名（manifest.json:21-26）。`web_accessible_resources` 四个文件：`options.html`、`options.js`、`icons/settings.svg`、`theme.css`（manifest.json:69-81），少一个页面就 404。

## 扩展 ID 怎么钉死

`manifest.key` 存的是 SPKI 公钥的 base64（manifest.json:68）。Edge/Chrome 装未上架的包时按这个 key 算 ID，所以重打包 ID 不变：

```
id = sha256(SPKI) 前 32 个 hex，每字符 97 + parseInt(c, 16)
```

现算出来是 `ecdedhcfflmobjlbcfanknhcpnnchefi`（build-extension.mjs:25-26）。私钥在 `build/wesley-cards-extension-key.pem`（build-extension.mjs:9），丢了就得换 ID、老用户全部重装。

| 步 | 干什么 | 位置 |
|---|---|---|
| 1 | 读或生成 2048-bit RSA 私钥 | build-extension.mjs:13-21 |
| 2 | 由公钥算 key 写回 `manifest.key` | build-extension.mjs:22-31 |
| 3 | （脚本注释直接从 2 跳到 4，没有这一步） | — |
| 4 | 用 python `zipfile` 打 `extension/wesley-cards-extension.zip`，跳过私钥、中间产物和脚本自己 | build-extension.mjs:33-50（skip 集合在 :40） |
| 5 | Edge 打 CRX：临时 user-data-dir + `--headless=new` + `--pack-extension` + `--pack-extension-key`，120s 超时，失败只打一行不抛 | build-extension.mjs:52-64 |
| 6 | 读 `manifest.version` 当标签，复制成根目录 `Better_WiSE_v<version>.crx` / `.zip`，删中间产物 | build-extension.mjs:66-81 |

跑一条：`node extension/build-extension.mjs`，末尾会打印 `EXTENSION_ID:`（build-extension.mjs:82）。Edge 路径写死在 `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`（:11），换机器要改。

## 版本号规则

- `manifest.json:4` 是唯一真源，每次改版 +1 末位：`0.1.2.16` → `0.1.2.17`。
- `options.js:162` 有一份兜底串 `{ version: '0.1.2.17' }`，必须跟着改。漏改的表现是设置页显示旧版本号（规则见 `000-入口/L0-钉住上下文.md:19`，设置页显示逻辑在 `options.js:824`）。
- 产物名自动跟 manifest 走，别手改：`Better_WiSE_v0.1.2.17.crx`。

## 别碰的地方

- 别为打包方便往扩展里加构建脚本、source map、依赖。现在包里 18 个文件、零依赖（`docs/SECURITY-REVIEW.md`），是给校方网络审查看的卖点。
- 别动 `permissions`。加一条就是重新走审批，现在只有 `storage`。
- 别手改 `manifest.key` 或换私钥，ID 一变就当新扩展处理了。
