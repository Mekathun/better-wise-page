## 三、探针（改完代码验证用）

`tools/probe/` 里常用这些，都是 `.mjs`，靠 CDP 跑：

| 探针 | 干什么 |
|---|---|
| `live-ext.mjs` | 带扩展起 Edge（L0 里那条命令行） |
| `audit.mjs` | 逐页白块审计，输出 `audit.json` |
| `audit-ui.mjs` | 弹层审计 |
| `fouc.mjs` | 首帧闪烁检测 |
| `perf.mjs` | 滚动性能 |
| `interact.mjs` | 交互回归 |
| `ui2.mjs` / `ui3.mjs` | 搜索覆盖层、详情模态 |
| `settheme.mjs dark\|light` | 切主题 |
| `shot.mjs` / `goto.mjs` | 截图 / 跳页 |
| `reload-ext.mjs` | 重载扩展 |

跑之前先 `taskkill //IM msedge.exe //F`。
